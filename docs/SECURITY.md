# 安全与隐私

## 敏感数据

以下内容都应视为凭据或隐私数据：

- 华为账号的 OAuth 授权码和令牌；
- 灯具 `authCode`；
- 设备 ID；
- 家庭局域网 IP、MAC 和拓扑；
- 华为智慧生活日志、APK、抓包和 HA 备份。

不要把这些内容提交到 GitHub、Issue、CI 日志或公开聊天。

## Home Assistant 中的保存位置

配置流程会把 IP、设备 ID 和 `authCode` 保存在 Home Assistant 配置条目中。它们不会由本集成发送给第三方，但会存在于 `/config/.storage` 和可能包含该目录的备份中。

建议：

- 限制 HA 配置目录和备份的访问权限；
- 对备份启用加密；
- 不在调试日志中打印配置条目数据；
- 不把 `.storage` 复制到代码仓库。

## 本地凭据助手

`tools/credential_web.py` 只监听 `127.0.0.1`，页面路径包含每次启动随机生成的秘密值，并发送 `no-store`、CSP、禁止嵌入等响应头。华为登录在独立的官方页面完成；工具只捕获最终 `hms://redirect_url` 回调。

工具不会显示或保存 OAuth access/refresh token。设备 ID 与 `authCode` 只在进程内存和本地页面中存在；清除页面或停止进程后丢弃。不要把监听地址改成局域网或公网地址。

命令行备用工具会生成包含本地凭据的 JSON 文件，权限设为 `0600`。它不包含 OAuth token，但仍应存放在密码管理器或加密目录，并保持在 Git 仓库之外。

## 网络隔离

可以把灯具放入 IoT VLAN，仅允许 Home Assistant 访问灯具 UDP `5686` 并接收回包。不要把该端口映射到公网。

## 凭据泄露后的处理

如果 OAuth 令牌泄露，应立即在账号安全设置中撤销相关授权或会话。如果设备本地凭据泄露，应重新配网或通过厂商支持的流程刷新设备授权，并更新 HA 配置。

## 报告问题

报告问题时请提供经过脱敏的 HA 错误类型、集成版本和设备型号。不要附带完整配置条目、原始数据包或厂商日志。
